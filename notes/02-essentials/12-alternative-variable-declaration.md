# alternative variable declaration

```go
	invesmentAmount := 1000            // <-- Default becoming int
	expectedReturnRate := float64(5.5) // Default becoming float
	years := "10"                      // Default becoming string
```
```go
	// This all type becoming float because point (5.5) in number 
	invesmentAmount := 1000.0 
	expectedReturnRate := 5.5 
	years := 10.0             
```
