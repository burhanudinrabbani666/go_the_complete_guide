# problem structs solve

In Go, a struct (short for "structure") is a user-defined composite data type that allows you to group together related fields of different types into a single unit.

Think of a struct as a blueprint or a custom record used to represent real-world entities, like a user profile or a product's specifications.

## Key Characteristics

- Heterogeneous Collection: Unlike arrays, which store multiple values of the same type, structs can store many different types (e.g., string, int, bool).
- Value Types: Structs are value types, meaning when you assign a struct to a new variable, Go creates a complete copy of the data.
- No Classes: Go does not have classes. Instead, structs are the primary way to implement object-oriented patterns.
